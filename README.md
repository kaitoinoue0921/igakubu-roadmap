# 医学部受験ロードマップ

地方の公立高校から医学部を目指す人向けに、ネット上の情報（予備校・医学部専門予備校・大学・官公庁・受験情報サイトなど100超のページ）を統合した1ファイルのWebページ。外部依存はGoogle Fontsだけで、オフラインでもシステムフォントで読める。

- `index.html` トップ（いまの場所、全体の地図、志望校タイプ別の違い、時期の目安、科目別、答案、入試方式、お金、地方から、割れている点、出典）
- `plan.html` 月ごとの計画（高1・高2は2か月ごと、高3・既卒は1か月ごと。志望校タイプ別の補足）
- `units.html` 単元ごとの目安（8科目・94単元。順番、時期、終えた基準、つまずき、医学部での位置づけ）
- `assets/data.js` 計画・単元・締切のデータ。内容の修正はここ。`assets/app.js` 表示、`assets/style.css` 見た目
- 学年・志望校タイプ・チェックは localStorage（キー `igakubu-roadmap-v1`）に保存し、3ページで共通。サーバーには何も送らない

## 年度の更新
- 日程は `assets/data.js` の `DEADLINES` と `PLAN.g3` の1〜3月、`index.html` の「2027年度入試の主な日程」の表。毎年夏〜秋に更新する
- 金額（学費・修学資金・奨学金）と配点・ボーダーも年度ごとに変わる
